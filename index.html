Neural Sequence Modeling · Benchmark

Nucleic Acid Binding Site Prediction: 1D CNN with Attention vs. Autoencoder Baselines

Repository → Live Demo →

Investigated residue-level RNA and DNA binding interface detection across 1,634 benchmark protein sequences (481,252 residues). Implemented a multi-scale 1D CNN integrated with a 4-head Multi-Head Self-Attention layer and masked Binary Cross-Entropy loss to manage variable sequence lengths (up to 1,781 residues), achieving 0.7340 AUC under severe class imbalance (~9.54% binding sites). Evaluated against an undercomplete convolutional autoencoder baseline.

Addressed the p >> n curse of dimensionality over 22,283 probe features and 105 biological samples using GEOparse, zero-variance screening, standard scaling, and PCA variance projection.
